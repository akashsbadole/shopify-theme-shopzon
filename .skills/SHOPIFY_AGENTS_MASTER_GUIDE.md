## 1. Agent Ecosystem Overview

### Core Agents (Full-Stack)

#### 1. Shopify Full-Stack Developer
- **File:** `.kiro/agents/shopify-full-stack-developer.md`
- **Best for:** Complete Shopify solutions, flexibility, rapid development
- **Capabilities:** Theme development, app development, custom functionality, troubleshooting

#### 2. Shopify Theme Developer
- **File:** `.kiro/agents/shopify-theme-developer.md`
- **Best for:** Theme-focused work, Liquid expertise, responsive design
- **Capabilities:** Theme creation, Liquid templates, sections, blocks, styling

#### 3. Shopify App Developer
- **File:** `.kiro/agents/shopify-app-developer.md`
- **Best for:** App-focused work, API integration, extensions
- **Capabilities:** App creation, Admin API, Storefront API, webhooks, billing

### Specialized Agents (Deep Expertise)

#### 4. Shopify Performance Optimizer
- **File:** `.kiro/agents/shopify-performance-optimizer.md`
- **Best for:** Performance optimization, Core Web Vitals, optimization strategies
- **Capabilities:** Performance analysis, optimization, monitoring, testing

#### 5. Shopify Security Specialist
- **File:** `.kiro/agents/shopify-security-specialist.md`
- **Best for:** Security hardening, compliance, vulnerability assessment
- **Capabilities:** Security audits, authentication, data protection, compliance

#### 6. Shopify API Integration Specialist
- **File:** `.kiro/agents/shopify-api-integration-specialist.md`
- **Best for:** API integration, GraphQL optimization, webhook implementation
- **Capabilities:** Admin API, Storefront API, GraphQL, webhooks, third-party integration

#### 7. Shopify Testing & QA Specialist
- **File:** `.kiro/agents/shopify-testing-qa-specialist.md`
- **Best for:** Testing strategy, test automation, quality assurance
- **Capabilities:** Unit testing, integration testing, E2E testing, performance testing

#### 8. Shopify DevOps & Deployment Specialist
- **File:** `.kiro/agents/shopify-devops-deployment-specialist.md`
- **Best for:** CI/CD, deployment automation, monitoring, infrastructure
- **Capabilities:** CI/CD pipelines, deployment automation, monitoring, logging

#### 9. Shopify Architecture & Design Specialist
- **File:** `.kiro/agents/shopify-architecture-design-specialist.md`
- **Best for:** System design, scalability, data modeling, architecture
- **Capabilities:** Architecture design, scalability planning, data modeling, design patterns

## 5. Getting Started Guide

### Step 1: Understand Your Project
- What are you building? (Theme, App, or both)
- What's your timeline?
- What are your priorities? (Performance, Security, Scalability)
- What's your team size?

### Step 2: Choose Your Approach

**Simple Project (1-2 weeks):**
- Use Full-Stack Developer
- Use Testing & QA Specialist
- Use DevOps Specialist

**Medium Project (2-4 weeks):**
- Use Architecture Specialist for design
- Use Full-Stack Developer or Specialized Agents for implementation
- Use Testing & QA Specialist for testing
- Use DevOps Specialist for deployment

**Complex Project (4+ weeks):**
- Use Architecture Specialist for design
- Use multiple Specialized Agents for implementation
- Use Testing & QA Specialist for comprehensive testing
- Use DevOps Specialist for deployment
- Use Performance Optimizer for optimization
- Use Security Specialist for security

### Step 3: Engage Agents

**For Theme Development:**
```
1. Theme Developer: Create theme
2. Performance Optimizer: Optimize
3. Testing & QA Specialist: Test
4. DevOps Specialist: Deploy
```

**For App Development:**
```
1. Architecture Specialist: Design (if complex)
2. App Developer: Implement
3. API Integration Specialist: Integrate APIs
4. Security Specialist: Secure
5. Testing & QA Specialist: Test
6. DevOps Specialist: Deploy
```

**For Complete Solution:**
```
1. Architecture Specialist: Design
2. Full-Stack Developer: Implement core
3. API Integration Specialist: Integrate APIs
4. Performance Optimizer: Optimize
5. Security Specialist: Secure
6. Testing & QA Specialist: Test
7. DevOps Specialist: Deploy
```

### Step 4: Monitor & Iterate
- Monitor performance
- Monitor security
- Monitor errors
- Iterate and improve
